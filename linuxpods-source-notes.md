# Fedora source preparation

The Fedora packages contain the LinuxPods daemon, command-line client and
Plasma 6 widget. Their source files declare `GPL-3.0-or-later`; the complete
license text is in `LICENSE`, installed by both binary packages. The widget
also declares its license in `plasmoid/metadata.json`.

LinuxPods derives from [LibrePods](https://github.com/kavishdevar/librepods).
The initial import identifies LibrePods commit
`1f2d70744fe6daa6f119172f1e4771300dd05814` in the LinuxPods git history.
Existing license notices are retained.

## Reproduce Source0

Run the script supplied as Source1, before creating an SRPM or uploading
sources to Fedora's lookaside cache:

```sh
python3 linuxpods-prepare-source.py 1.0.2
```

The script downloads:

```
https://github.com/Explor3Universe/LinuxPods/archive/v1.0.2/linuxpods-1.0.2.tar.gz
```

It requires this upstream SHA256:

```
61d778de1adadf5aa981f2ab3505cea41e10c4e4619ad7a2d09b02384ff606bc
```

To work offline, pass `--upstream-archive /path/to/linuxpods-1.0.2.tar.gz`.
Use `--output-dir /path/to/SOURCES` to choose the destination.

The result is `linuxpods-1.0.2-fedora.tar.gz`. Entries are sorted, owner/group
metadata is normalized, and the gzip header has no filename or timestamp.
Retained files preserve their upstream contents, permissions and timestamps.
The script does not apply patches or add license declarations.

The repacked archive's SHA256 is:

```
3332e071bd93712a35f7a2b2ee5758b42edf3c9251667101003d4b2972c2899f
```

## Excluded content

| Paths | Reason |
| --- | --- |
| `src/assets/` | Standalone GUI artwork and desktop/AppStream metadata, unused by the Plasma widget. No distribution rights are assumed for product images. |
| `src/thirdparty/` | MIT-licensed QR-Code-generator, used only by the standalone GUI. The CMake patch removes it from the daemon target. |
| `src/translations/`, `src/*.qml` | Standalone GUI translations and QML. |
| `src/main.cpp`, `src/trayiconmanager.*`, `src/QRCodeImageProvider.hpp` | Standalone GUI entry point, tray integration and QR image provider. |
| `design/` | Design mockups, not build or runtime inputs. |
| `docs/` | Protocol research notes and an auxiliary key-extraction script, not build or runtime inputs. |
| `.gitignore`, `build.sh`, `linuxpods.spec`, `linuxpods.rpmlintrc` | Upstream repository/packaging helpers; the maintained Fedora packaging inputs are supplied separately in the SRPM. |

These files are absent from Source0 itself, not just deleted during `%prep`.
The upstream git tag is unchanged. All sources needed for the daemon, CLI
and Plasma widget, including their build files and D-Bus interface, remain.
The QR library is neither included nor linked in the Fedora packages, so
there is no `bundled(qr-code-generator)` provide.

## Review notes

`linuxpods-plasmoid` is `noarch` and requires exactly the matching
`linuxpods = %{version}-%{release}`. Adding `%{?_isa}` would make this
architecture-independent package depend on the build machine's architecture.
The Fedora "Requiring Base Package" guideline limits that requirement to
non-noarch packages.

The systemd user unit uses `%systemd_user_post`, `%systemd_user_preun`, and
`%systemd_user_postun_with_restart` in their corresponding scriptlets.
No service preset is shipped. Enable the daemon with
`systemctl --user enable --now linuxpods-daemon`.

The systemd warning from fedora-review 0.12.0 can be reproduced even when
the RPM scriptlets match these macros' expansions exactly. Inspect the
actual RPM with `rpm -qp --scripts linuxpods-*.x86_64.rpm`; a failed
regular-expression match in the review tool is not evidence of a missing
scriptlet.

Using Rawhide's licensecheck 3.3.10 and `licensecheck -r` on the old
1.0.2-4 build directory immediately after `%prep` reproduces seven unknowns:

| File | Resolution |
| --- | --- |
| `build.sh`, `linuxpods.rpmlintrc` | Obsolete copies of packaging helpers, excluded from the repacked archive. The current build and source-preparation scripts have SPDX headers. |
| `docs/AAP Definitions.md`, `docs/Proximity Pairing Message.md`, `docs/proximity_keys.py` | Unused research material, excluded from the Fedora archive rather than assigning new licenses to it. |
| `LICENSE` | The complete GNU GPL version 3 text, preserved verbatim and installed as `%license`. The scanner does not recognize this file as a license grant. The source headers and widget metadata specify `GPL-3.0-or-later`. |
| `rpmbuild.env` | Environment snapshot generated by RPM outside the unpacked upstream directory, not an upstream or installed file. |

The last two scanner results can therefore remain for the new package.
They must be explained during manual review, not hidden by changing the
license text or deleting RPM's build records. Scans run after compilation
may additionally include generated CMake and Qt AUTOMOC files.
